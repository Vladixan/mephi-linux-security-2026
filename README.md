# mephi-linux-security-2026
Training on the OS security program, student №374210

Раздел 1. Создание пользователя
  groupadd students // для создания группы с названием "students".
  useradd -u 1234 -G students // для добавления пользователя "user1" с идентификатором 1234, который будет входить в группу "students".  
  passwd user1 // задан пароль для пользователя "user1".
  chage -M 90 -W 5 user1 // для настройки необходимости смены пароля для пользователя "user1" через 90 дней и настройки выдачи уведомления о такой необходимости за 5 дней до истечения срока.
  Командой chage -l user1 проверено добавление этой настройки.
  Командами cat /etc/group и cat /etc/passwd проверено создание группы "students", создание пользователя "user1" и его добавление в группу "students".

Раздел 2. Мониторинг файлов и процессов
2.1. Мониторинг файлов
  find / -perm /u=s // для поиска файлов, у которых для для владельца установлен бит s. Список выведен в файл Task2_1.txt командой find / -type f -perm /u=s > Task2_1.txt.

2.2. Мониторинг процессов
  Перед выполнением команды во втором терминале произведён вход пользователя user1 и начат процесс смены пароля с помощью команды passwd.
  ps -eo pid,user,ruser,comm | awk '$2 == "root" && $3 != "root"' > Task2_2.txt // для поиска процессов, у которых эффективный UID равен 0, а реальный UID относится к обычным пользователям, и вывода в файл Task2_2.txt.

Раздел 3. Изучение механизма set-UID
3.1. Выбор утилиты
  Выполнена команда cat /etc/shadow за пользователя user1. Результат выполнения - "Отказано в доступе".

3.2. Выполнение привилегированной операции с помощью механизма set-UID
  cp /bin/cat ~/user_cat // за пользователя user1 утилита cat скопирована в домашнюю папку пользователя под именем user_cat.
  chown root:root /home/user1/user_cat // за пользователя root выполнено изменение владельца /home/user1/user_cat на пользователя root.
  chmod u+s /home/user1/user_cat // за пользователя root установлен бит Set-UID для /home/user1/user_cat.
  ~/user_cat /etc/shadow // за пользователя user1 выполнено успешное чтение файла /etc/shadow.

Раздел 4. Изучение механизма привилегий
4.1. Выбор утилиты
  touch Task4.txt // за пользователя user1 создан файл для выполнения задания.
  Выполнена команда chown root:root ~/Task4.txt за пользователя user1 для смены владельца файла Task4.txt на root. Результат выполнения - "Операция не позволена".

4.2. Выполнение привилегированной операции с помощью механизма привилегий
  cp /bin/chown ~/user_chown // за пользователя user1 утилита chown скопирована в домашнюю папку пользователя под именем user_chown.
  setcap cap_chown+ep /home/user1/user_chown // за пользователя root выполнено повышение привилегий для /home/user1/user_chown.
  ls -l ~/Task4.txt // за пользователя user1 проверено, что владельцем Task4.txt по-прежнему является user1.
  ~/user_chown root:root ~/Task4.txt // за пользователя user1 выполнена смена владельца Task4.txt на пользователя root.
  ls -l ~/Task4.txt // за пользователя user1 проверено, что владельцем Task4.txt теперь является root.

Раздел 5. Изучение механизма sudo
  За пользователя root выполнено редактирование файла /etc/sudoers командой visudo. Добавлена строка user1 ALL=(root) /usr/bin/timedatectl, /usr/bin/date
  sudo date -s "2026-09-16 14:33:30" // за пользователя user1 изменено системное время.

Раздел 6. Сбор артефактов
